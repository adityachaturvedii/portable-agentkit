# Domain procedures

Load only the procedure needed for the task. All seven are initial requirements, not execution integrations.

- [ml-experiments](ml-experiments.md): A change to data preparation, model selection or experiment conclusions.
- [training-correctness](training-correctness.md): A change to loss, gradients, precision, optimizer, resume or distributed training.
- [cuda-kernels](cuda-kernels.md): A CUDA implementation or kernel performance claim.
- [inference](inference.md): An inference backend, batching, caching or serving performance change.
- [backend-database](backend-database.md): A backend contract, retry, transaction or schema migration change.
- [enterprise-llm-graphs](enterprise-llm-graphs.md): An LLM tool workflow, retrieval pipeline or graph transition change.
- [frontend](frontend.md): A user-visible web flow, layout or accessibility change.
