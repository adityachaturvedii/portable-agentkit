# Enterprise llm graphs

Trigger: An LLM tool workflow, retrieval pipeline or graph transition change.

1. Use held-out retrieval/question cases and report relevance/answer correctness separately. Model agreement is not an independent oracle.

2. Exercise tool permission and tenant boundaries with malicious retrieved text, forged approvals and cross-tenant identifiers. Content cannot grant effects.

3. Bound transitions, retries and budgets in trusted code; test checkpoint/resume, duplicate events and partial failures with fake tools. A prompt rule does not prove enforcement.

Stop: Trusted transition/permission enforcement unavailable, protected evaluation contaminated or actual billing authorization absent.

Output: add the relevant checks, identities and evidence to the parent skill handoff; record missing capabilities in limitations. This procedure supplies requirements, not an installed tool or tested execution adapter.
